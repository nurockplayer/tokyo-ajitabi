# TOKYO AJITABI MVP

## 1. 一句話說明

東京都民の好みや時間に合わせて、地域の食文化・生産者・観光スポットを巡る体験ルートを提案し、スタンプのように記録を集められるサービス。

## 2. 解決的問題

- 東京の地域食文化に関する情報が複数のサイトに分散している
- 有名観光地以外の地域や生産者が知られにくい
- 食文化の背景や作り手の物語まで知る機会が少ない
- 一度きりの観光では、別の地域を再訪する動機が生まれにくい

## 3. MVP 的主要使用者

東京に住んでいるが、奥多摩や多摩地域の食文化をよく知らない東京都民。

## 4. Demo 使用流程

1. 利用者が時間・移動手段・興味を選択する
2. 条件に合う奥多摩のモデルコースが表示される
3. 各スポットで食文化・生産者・地域の物語を確認する
4. コース完了後、デジタルスタンプを獲得する
5. 次に巡れる地域やコースが表示される

## 5. MVP 必做功能

- 条件選択画面
- 奥多摩モデルコース提案
- ルート内スポット一覧
- 食文化・生産者ストーリー表示
- スタンプ獲得・コレクション画面
- 使用したオープンデータの表示

## 6. Demo 階段不做

- 完全自由生成のAI旅行プラン
- 東京都全域の実データ登録
- 店舗予約・決済
- GPSによる厳密な訪問判定
- SNS・ユーザー投稿
- 複雑なアカウント管理

## 7. 使用資料候選

- 東京都オープンデータ
- 奥多摩町・観光協会の公開情報
- 交通・施設・観光スポットデータ
- 現地フィールドワークで収集した一次情報
- 生産者・店舗の公式Webサイト

## 8. Demo 完成條件

- 3分以内で一連の体験を説明できる
- 少なくとも1本の奥多摩ルートが最後まで動作する
- 各スポットにデータ出典がある
- オープンデータがルート提案または情報表示に使われている
- スタンプ獲得まで操作できる
